# ORBIVEX — Go Beyond Ordinary 🌍✨

An immersive, cinematic luxury travel website blending 3D interactivity, storytelling, and modern editorial aesthetics.

Built with **React**, **Three.js / React Three Fiber**, **GSAP**, **Tailwind CSS**, and **Framer Motion**.

---

## ✨ Features

- **🌐 Interactive 3D Globe**: Custom interactive Three.js globe featuring glowing atmospheres, continental landmass rings, flight arc trajectories, and interactive destination coordinates.
- **🧭 Editorial Navigation & Quick Search**: Glassmorphic sticky navbar with real-time quick search overlay, destination filter categories, and quick navigation shortcuts.
- **🏔️ Curated Destination Catalog**: High-resolution showcase of exotic world destinations with interactive cards, tag filters, and fluid hover animations.
- **⚡ Cinematic Video Storytelling**: Interactive story viewer with custom video controls, immersive captions, and dynamic ambient lighting.
- **🗺️ Interactive Travel Planner**: Interactive trip customization wizard allowing users to tailor styles, continents, durations, and receive instant personalized itinerary previews.
- **📖 Journal & Editorial Chronicles**: Luxury travel articles and field notes with reading time estimates, categories, and typography inspired by editorial print.
- **🎭 Micro-Interactions & Custom Cursor**: Dynamic mouse tracker adapting to interactive elements, custom scrollbar, and smooth GSAP transitions.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **3D Graphics**: Three.js, @react-three/fiber, @react-three/drei
- **Animations**: GSAP (ScrollTrigger), Framer Motion
- **Styling**: Tailwind CSS, Vanilla CSS animations
- **Icons**: Lucide React
- **Audio/Video**: Native HTML5 Media APIs

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/GOUNINIKHILGOUD07/ORBIVEX-.git

# Navigate into the project
cd ORBIVEX-

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Production Build
```bash
# Build optimized bundle
npm run build

# Preview production build locally
npm run preview
```
visit the website orbivex-gold.vercel.app
